Kebijakan Privasi Istiqomah

Berlaku sejak 4 November 2026

Istiqomah adalah aplikasi daftar tugas dengan kalender dan jadwal sholat. Halaman ini menjelaskan data apa yang disimpan dan bagaimana data itu dipakai.

Data di perangkat

Tugas, catatan sholat, pengaturan, lokasi yang dipilih untuk menghitung jadwal sholat, dan foto background tersimpan di perangkat kamu. Jadwal sholat dihitung di perangkat, jadi lokasi tidak dikirim untuk keperluan itu.

Kalau kamu masuk dengan email

Alamat email dipakai untuk mengirim kode masuk. Salinan tugas, catatan sholat, dan pengaturan disimpan di server Supabase (wilayah Singapura) supaya bisa dipakai di perangkat lain. Setiap pengguna hanya bisa mengakses datanya sendiri. Foto background tidak ikut dikirim.

Kalau kamu menghubungkan Google Calendar

Sambungan ini pilihan dan bisa diputuskan kapan saja. Istiqomah meminta izin berikut:

  • Melihat daftar kalender dan acaranya, supaya acara kamu tampil di halaman Hari ini dan Kalender.
  • Membuat kalender bernama Istiqomah dan mengelola acara di dalamnya, supaya tugas dan jadwal sholat masuk ke Google Calendar beserta pengingatnya. Kalender lain tidak diubah.

Acara dari Google tidak disimpan di server Istiqomah. Acara hanya diteruskan ke aplikasi dan disimpan sementara di perangkat kamu. Token akses Google disimpan terenkripsi di server dan hanya dipakai untuk fungsi di atas.

Penggunaan data Google

Penggunaan informasi yang diterima dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use. Data Google tidak dijual, tidak dipakai untuk iklan, tidak dipakai untuk melatih model AI, dan tidak dibagikan ke pihak lain, kecuali penyedia layanan yang dibutuhkan untuk menjalankan fitur di atas.

Penyedia layanan

  • Supabase: tempat data dan akun disimpan.
  • Google: Google Calendar dan pengiriman email kode masuk.
  • GitHub Pages: tempat aplikasi ini disajikan.

Menghapus data

  • Putuskan Google Calendar di Pengaturan > Akun dan kalender, atau cabut aksesnya di halaman izin akun Google.
  • Hapus data di perangkat lewat Pengaturan > Hapus semua data.
  • Untuk menghapus akun beserta data di server, kirim email ke alamat di bawah.
